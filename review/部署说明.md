# 高清片源搜索转换器 · 部署说明

## 这个东西解决什么问题

新6V（xb6v.com）这类高清站是"网页"，影视仓/TVBox 客户端读不懂网页，所以搜不出、播不了。
这个转换器把网页搜索转成客户端能懂的标准接口（苹果CMS JSON），部署后你的客户端就能搜到高清片。

## 重要前提（先看这个）

新6V的高清片给的是**磁力链接**（`magnet:?xt=urn:btih:...`）和网盘链接，不是在线视频流。
- 影视仓/TVBox 客户端本身**不能播磁力**（磁力需要先下载，电视盒子通常没下载器）
- 所以：搜索能用，但点开播放需要你的播放器支持磁力/网盘嗅探，或跳转下载

如果你只是要"搜到片名、看到封面"，这个转换器完全够用；
如果你要"点开直接播高清"，磁力源在电视上做不到，需要换成在线流源（那些就是低码率采集站）。

## 部署步骤（2分钟，免费，无需信用卡）

1. 打开 https://dash.cloudflare.com/ 用邮箱注册/登录（免费账号即可）

2. 左侧菜单点 **Workers & Pages** → **Create** → **Create Worker**

3. 起个名字，比如 `hdsearch`，点 **Deploy**

4. 部署后点 **Edit code**，把本目录 `worker.js` 的全部内容复制粘贴进去，覆盖默认代码，点 **Deploy**

5. 得到访问地址，形如 `https://hdsearch.你的用户名.workers.dev`

## 在影视仓里使用

把下面地址里的 `你的用户名` 换成你自己的，填到影视仓的"配置地址"或作为一个新站点：

```
https://hdsearch.你的用户名.workers.dev/?ac=detail&wd=关键词
```

作为站点配置（加到配置文件的 sites 数组）：
```json
{
  "key": "hdsearch",
  "name": "高清搜索",
  "type": 1,
  "api": "https://hdsearch.你的用户名.workers.dev",
  "searchable": 1,
  "quickSearch": 1,
  "changeable": 0
}
```

## 接口说明

- `?ac=list` — 返回分类列表
- `?ac=detail&wd=片名` — 搜索（已内置成人分类过滤）
- `?ac=detail&ids=片ID` — 详情（提取磁力/网盘/直链）
